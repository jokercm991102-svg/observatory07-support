# ✦ 07 觀測站 (Observatory 07) — 官方技術支援與隱私權政策

## 一、使用者技術支援與聯絡我們 (User Support & Contact)
若您在使用《07 觀測站》時遇到任何操作疑問、問題回報或建議，歡迎透過以下方式與開發團隊聯繫：
- **開發團隊 (Developers)**：Chun-Yen Wang & Yuan-Che Wang (王俊彥、王元哲)
- **支援語言 (Supported Languages)**：繁體中文、简体中文、English、日本語、Deutsch、Français
- **聯絡與回報方式 (Contact)**：請直接點選 [**Issues ➔ New Issue**](https://github.com/jokercm991102-svg/observatory07-support/issues/new) 留言回報，我們將於 24–48 小時內回覆處理。

## 二、隱私權政策 (Privacy Policy)
《07 觀測站（Observatory 07）》高度重視您的個人隱私。本應用程式採用 **100% 離線與裝置端本地運算架構**，我們不會收集、儲存、追蹤或上傳您的個人身分資訊、照片或影像資料：
1. **相機權限 (Camera Usage)**：相機僅用於裝置端記憶體即時分析環境光線之像素色彩（RGB / OKLab），不會在背景自動錄影或上傳任何影像至外部伺服器。
2. **相簿寫入權限 (Photo Library Additions)**：僅在您主動點擊「分享光籤海報」並選擇「儲存影像」時，將產生的海報圖片存入您的裝置相簿。
3. **動作與方向感測 (Motion Usage)**：陀螺儀僅用於「銘心星鑑」星座圖之 360° 視差檢視與觀測穩定度判定，不會記錄或外傳任何身體活動數據。
4. **本機儲存 (Local Storage)**：所有觀測紀錄僅保存在您的 iOS 裝置本機，可隨時於 App「系統設定 ➔ 重置所有進度」中完整清除。

### English Privacy Policy Summary
**Observatory 07** processes all camera color sampling locally on your device in real time. We do **not** collect, store, track, or transmit any personal data, photos, videos, or location information to external servers.
